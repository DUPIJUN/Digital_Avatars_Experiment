# 利用数字形象再现亲社会行为中的性别年龄偏倚实验复现
## 1、实验设计
本研究采用2（数字形象年龄：年轻vs老年）× 2（数字形象性别：男性vs女性）的被试内设计。因变量为疼痛感知强度和亲社会行为（帮助意愿），调节变量为特质共情水平。
为考察共情连续体中疼痛感知与帮助决策的关系，本研究参考Coll等人及Bélanger等人的实验范式进行设计。与原文献将疼痛感知任务和帮助决策任务分为先后两个独立block的做法不同，本研究将两者整合为同一试次：被试观看动态数字形象的疼痛表情后，屏幕上同时呈现两个视觉模拟量表（VAS），上方为疼痛感知强度评定，下方为帮助意愿评定。被试在同一界面完成两次评定后，系统根据帮助意愿计算等待时间，并呈现不同程度帮助后数字形象疼痛缓解的反馈画面。此外，原文献中帮助决策的最大等待时间为20秒，本研究将其缩短至15秒，以进一步减少单次试次时长和被试整体负担。
这一调整的主要目的是简化实验流程、减少被试认知负荷和实验时长，同时保持对共情连续体两个阶段的同时测量。在样本量有限（N=72）的情况下，该设计既能提高生态效度，又能确保实验的可行性。
## 2、实验说明
本实验采用PsychoPy2025.2.3版本软件进行实验编程并呈现刺激材料。由于未获得有效的邮箱地址验证，本研究未能采用Pavlovia线上托管平台，所有实验均在心理实验室本地电脑上离线运行。实验前，所有被试均完成抑郁筛查和知情同意程序。正式实验开始前，被试需先完成中文版人际反应指数量表，随后进入正式任务。
正式实验任务共包括24个试次，采用完全随机呈现顺序。为避免顺序效应，所有刺激的年龄与性别组合在被试间实现平衡。实验在安静的心理实验室进行，被试与屏幕距离约60cm，屏幕分辨率为1920×1080像素，环境亮度保持一致。
单个试次的具体流程如下：

**1.	屏幕中央呈现500ms的注视点“+”。**

**2.	呈现2秒的动态数字形象疼痛表情视频（低强度疼痛、高强度疼痛或中性表情）。**

**3.	视频结束后，屏幕上同时呈现两个视觉模拟量表（VAS）：上方为疼痛感知强度评定（0=无疼痛，100=最大疼痛），下方为帮助意愿评定（0=完全不提供帮助，100=提供最大帮助）。被试使用鼠标拖动滑块完成两评定后点击“提交”。**

**4.	根据被试在帮助意愿VAS上的得分，系统自动计算等待时间（最高15秒，最低0秒），屏幕显示“正在提供帮助，请等待…”的进度条。**

**5.	等待结束后，呈现帮助反馈画面：数字形象的疼痛表情逐渐缓解至中性或低强度或者原状态，持续1秒。**

**6.	试次间间隔为1000ms，进入下一个试次。**

整个正式实验任务约持续15分钟，无中间休息环节。
实验开始前，主试向被试宣读标准化指导语：“您将看到一些数字形象的表情视频。请先评估您感知到的疼痛强度，再评估您愿意提供多少帮助。帮助越多，您需要等待的时间越长，但您会看到帮助后对方疼痛缓解的情况。请根据真实感受作答。”实验结束后，被试完成简短的实验感受报告，并获得报酬与心理健康资源信息。

## 3、实验复现
### 一、软件下载
本实验采用psychopy实验设计软件进行实验操作，您可以点击[Psychopy下载地址](https://www.psychopy.org/download.html)进行实验软件的下载。本实验所用版本为PsychoPy2025.2.3，您可以在下载官网找到历史版本或相关GitHub及相关托管网站上找到对应版本资源。

### 二、操作指导
点开该实验的GitHub界面，您可以看到一些文件及文件夹，其中文件夹**data**是实验进行之后存放实验数据的地方；文件夹**videos**是本实验所用实验刺激视频；表格文件**conditions**是视频刺激呈现逻辑的依据；表格文件**practice_conditions**是实验练习所用的视频刺激呈现逻辑。文件**experiment**则是本实验的主程序，您需要打开您下载好的[PsychoPy](https://www.psychopy.org/download.html)软件，在软件内点击**open**选项并选择**experiment**以打开实验。

进入软件界面后，您可以看到实验程序的呈现逻辑，从前到后分别为**instr** **(instruction)**、**practice_loop** **(练习循环)**、**trials** **(正式实验循环)**。每个实验循环内都包含各种不同的组件，包括*code*、*keyboard*、*text*、*slider*、*video*、*polygon*等，分别实现“**自定义操作代码**”、”**导入键盘出发操作逻辑**“、“**展示实验文本**”、“**导入滑动轴交互框**”、“**导入视频刺激**”、“**导入准备信号（刺激间隔）**”的功能。点击**run**来正式运行实验。实验运行结束后，您可以在**data**文件夹中找到刚才的实验数据

### 三、实验刺激
如果您对实验材料的制作感兴趣，您看一观看本文件夹中有关FACS AU动作单元说明的文档以及[Blender](https://www.blender.org/download/)的插件[CharMorph](https://github.com/Upliner/CharMorph)，本实验的实验刺激均基于开源软件Blender以及开源插件CharMorph进行制作，无任何私有内容。视频制作采用Blender软件内置的Shape Keys功能来制作刺激动画。关于本实验所制作的数字形象的模板文件，已经放在**Blender_Template**文件夹中，您可以自行下载[Blender](https://www.blender.org/download/)以打开该文件进行相关操作。

如果您有对本实验相关的困惑，可在**Essays**文件夹中查阅本实验文献与模板实验文献*Reproducing age and sex biases in perceived pain intensity and prosocial behavior* 。至此，本实验演示说明结束
